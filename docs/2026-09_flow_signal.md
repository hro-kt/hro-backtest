# 締切直前の資金移動シグナル — 調査結果と今後の計画（2026-09-19）

## 要約

1週間かけて「現行モデルの情報量の天井は複勝 ROI **0.85**」を測り切り、従来型の改善（選別・血統・
アブレーション・セグメント・券種・市場価格）が**すべて1ポイント未満**であることを確認した。
その後、外部レビューの指摘を受けて**価格経路**に方向転換したところ、天井の外にある情報源が見つかった。

**結論**: 締切直前の単勝プールの資金移動には予測力がある。11年中11年で再現し、
決定時点で見える情報だけを使った運用形で **複勝 ROI 1.174（P(ROI≤1)=0.001、8ヶ月中8ヶ月）**。

---

## 1. 前提（制度）

- パリミュチュエル。払戻は**締切後に確定した最終オッズ**で決まる。締切前のオッズは推定値。
- 控除率: 単勝・複勝 20% / ワイド 22.5% / 三連複 25%。無作為の期待 ROI は 0.80 / 0.775 / 0.75。
- **売り（ショート）不可**。市場の過大評価は利用できず、過小評価だけが利益源。
- 複勝は8頭以上で3着まで、5〜7頭で2着まで払戻。

## 2. 天井の測定（1週目）

### 2.1 モデルは市場を超える情報を持つ

**市場超え検定**（確定オッズで層化し、帯内でモデル確率の分位を比較）:

| 帯数 | モデル | 負の対照（score=1/odds） |
|---|---|---|
| 10 | +0.149 | +0.025 |
| 100 | **+0.127** [+0.092, +0.162] | **−0.021** [−0.054, +0.014] |

対照は帯を細かくすると 0 に収束し、モデルは +0.127 で一定。**市場に直交する情報は実在する**。

> 検定側のバグ（同値の閾値割当で上位群が20%からずれる Simpson 型の合成バイアス）を
> 順位割当に修正して判明。当初の +0.166 は約2pt膨らんでいた。

### 2.2 しかし水準は 0.85 で飽和

絞り込みを深めても動かない: 上位20% 0.840 / 5% 0.846 / 2% 0.854。最良セルでも 0.885。

### 2.3 試して効かなかったもの（すべて1pt未満）

| 手 | 結果 |
|---|---|
| 選別（オッズ帯・確率分位・er帯・較正・EV下側信頼限界） | 天井不変 |
| レース条件30セグメント（頭数/馬場/距離/道悪/格/場/月） | 全て P(ROI≤1)=1.000、範囲 0.776〜0.881 |
| 血統バグ修正（母父が全行空→復活、母IDの衝突解消） | 複勝 −0.008、**新馬でも +0.004 [−0.009, +0.017]** |
| 本番アブレーション11フラグの全解除 | +0.009 [−0.002, +0.020] |
| 市場価格を素の特徴に | AUC/logloss は改善するが **ROI −0.035** |
| 同じく init_score オフセット（+忍耐300/lr0.02） | 帯内差 +0.137 < 市場なし +0.149 |
| オッズ帯別の再較正 | **ROI −0.023** [−0.038, −0.007] |
| 券種（単勝） | 帯内差 +0.044、複勝より劣る |
| 市場参照スライサー（約36軸・約300ビン） | **全ビン \|実測−市場\| ≤ 0.01** |

**市場価格に条件付けるものは何であれ ROI を下げる**（4例）。機序: GBM は強い特徴を与えられると
自前の弱い信号を捨てて寄りかかる。帯内で較正すると直交成分そのものを潰す。
**AUC の改善は成果ではない**——賭けに要るのは絶対精度ではなく市場との直交成分。

## 3. 発見（2週目）

### 3.1 現象: 締切直前の資金移動

JRDB TYB の直前単勝オッズ（2015年〜11年分）→ 確定単勝オッズ のプール占有率変化を、
確定複勝オッズ100帯で層化して検定:

| | 差 | 対照 |
|---|---|---|
| 全体（n=562,433 / 40,372R） | **+0.144** [+0.126, +0.163] P=0.000 | +0.004 [−0.013, +0.021] |

**年別 11/11 年で正、全年 P<0.05**。しかも近年ほど強い（2016 +0.073 → 2025 +0.268）。

分解すると主成分は「変化」ではなく**確定時点でのプール間乖離**:
`level_start +0.014 / level_end +0.109 / flow +0.144`。
= Hausch–Ziemba の place/show 非効率。起点の（情報の無い）成分を引くと信号が研がれる。

### 3.2 運用形（決定時点の情報のみ）

- 信号: `ts_o1`（公式時系列オッズ 0B41、2025-09〜2026-08）の **T−6分 → T−60秒** の
  単勝プール占有率 `1/tan_odds` の logit 差
- 選別: fit 期間（その月より前の全データ）の分位 0.95 を**絶対閾値**にして eval 月に適用
- 決済: `nl_hr` の実払戻
- **フィットするパラメータは無い**（占有率の logit 差で並べるだけ）

| 券種 | ROI | P(ROI≤1) | 月別 | 的中 | 平均odds | 本数/月 |
|---|---|---|---|---|---|---|
| **複勝** | **1.1741** [1.058, 1.298] | **0.001** | **8/8** | 34.2% | 3.61 | 約185 |
| 単勝 | 1.163 | 0.023 | 8/8 | 11.5% | 18.2 | — |
| ワイド | 1.748（分位0.99） | 0.001 | 8/8 | 7.6% | 33.6 | 約212 |
| 三連複 | 0.64〜0.77 | 0.79〜0.96 | 3〜5/8 | 0.5% | 800+ | — |

複勝の月別 ROI: 0.952 / 1.037 / 1.091 / 1.116 / 1.183 / 1.363 / 1.507 — **特定月への依存なし**。
閾値に対しても単調（0.95→1.174 / 0.98→1.098 / 0.99→1.067 / 0.995→0.989）。

### 3.3 リーク監査

`post_ts − snapshot_ts` は p05/中央値/p95 とも **60秒**（0B41 は発走1分前配信の格子）。
**締切後を拾った行 0 / 48,329**。実際の決定時点は T−60s で、想定より保守的。

### 3.4 自己インパクト

票数（H1）を2002年から再パース（`nl_h1`、オッズ再現率 99.0%）。払戻式は当てにいかず、
実払戻から配当原資を逆算（検証: 着内馬の原資合計 ÷ (プール×0.8 − 着内票数合計) の中央値 **0.965**）。

| 1点 | ROI | 8ヶ月の利益 |
|---|---|---|
| ¥10,000 | 1.171 | ¥2.5M |
| ¥50,000 | 1.158 | ¥11.7M |
| ¥100,000 | 1.144 | ¥21.3M |
| **¥200,000** | **1.117** | **¥34.7M** |
| ¥500,000 | 1.053 | ¥38.9M（頭打ち） |

複勝プールは1レース数億円規模で、対象馬の票数は数千万〜1億円相当。20万円の希釈は1%未満。
**信号は単勝プールから取るので、複勝に賭けても信号源は汚れない**。

## 4. 採否の判断

| 対象 | 判断 | 理由 |
|---|---|---|
| **複勝・分位0.95** | **採用候補** | 閾値に対して単調、月別に偏りなし、的中34%で分散が小さい、P=0.001 |
| ワイド | **保留** | 分位に対して非単調（0.99 だけ突出）。的中約130本を数本の高配当が支配 |
| 単勝 | 不採用 | 成立はするが的中11%・平均18倍で分散が大きい |
| 三連複 | 不採用 | 全選別で 1.0 未満、月別 3〜5/8 |
| `xpool_level`（プール水準乖離） | 不採用 | 構造的な非線形写像を拾い、ただの人気馬選別器（的中42%・odds 2.12・ROI 0.85） |

## 5. 今後の計画

### 5.1 実弾前に必須

1. **ライブ取得の確認**: `0B41` が発走前に取れるか（開催日に `fetch-timeseries-odds --specs 0B41`）。
   取れなければ自前の `poll-odds`（10秒周期、`ts_sokuho_o1`、実装済）で T−6m / T−60s を作る。
   この場合は前向き収集の開始待ちになる。
2. **`poll-odds` の常時稼働**: 開催日に自動で回る形にする。上記の代替経路であり、
   ワイドの運用形検証（`ts_sokuho_o3` の蓄積）にも要る。
3. **`race_day.py` への組み込み**: T−60s に信号を計算し、閾値超えの馬券を `prediction_log` に記録。
4. **前向きペーパー**: 実時間で同じ手順を回して再現を見る。**これを通すまで実弾は入れない**。
   バックテストで有望に見えたものが条件を変えると消える経験を、この調査だけで複数回している。

### 5.2 運用設計の論点

- **執行**: T−60s に判断するので、締切までに発注を終える必要がある。開催日あたり約8点。
- **運転資金**: 1点20万円 × 月185本 ≒ 月3,700万円。
- **閾値の更新**: fit 期間を拡大窓で更新し続ける（月次）。閾値は絶対値で固定し、未来を見ない。

### 5.3 並行して観察

- ワイド: 同じ信号で選別できるので、前向きペーパーに含めて実時間の挙動を見る（実弾は複勝のみ）。
- `ts_sokuho_o3/o5` の蓄積: 組券種の決定時点オッズは過去分を取得できない（`0B33/0B35` は
  当日のみ配信）ため、前向き収集でしか貯まらない。

## 6. 残るリスク

- **運用形の検証は単一の12ヶ月間のみ**。`ts_o1` の保持が1年で窓を増やせない。
  現象自体は11年で再現しているが、運用形の数字は1年分の証拠しかない。
- **実時間での再現は未検証**。
- 自己インパクトの見積もりは、配当原資の逆算（検証 0.965）に依存する。
- 近年ほど信号が強くなっている（2016 +0.073 → 2025 +0.268）。構造変化の可能性があり、
  逆に将来弱まる可能性もある。

## 7. この調査で得た手続き上の教訓

- **推測でバイト位置を置かない**。UM 3代血統（繁殖登録番号 8B→10B の誤り）、TYB の直前オッズ、
  H1 の票数配列——いずれも実データで検証してから確定させた。H1 は「票数×オッズが全頭で一定」
  という恒等式で総当たり検証し、仕様書なしに位置を特定した。
- **データは「無い」のではなく「使っていない」ことが多い**。`ts_o1`（1年分）は取得経路を
  知らず、TYB の直前オッズはパーサが意図的に捨てており、H1 は `raw_only` のままだった。
- **単一期間の有望な数字は採用しない**。この調査だけで、窓を増やすと消えた例が複数ある
  （wide の +0.039 → 7窓で −0.077 など）。
- **負の対照を必ず置く**。市場超え検定の +0.166 は、対照（score=1/odds）を測って初めて
  +0.127 に訂正できた。
